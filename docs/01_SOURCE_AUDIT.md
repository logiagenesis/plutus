## Conflict register and proposed resolution
| Conflict or issue | Resolution for the proposed build |
|---|---|
| GPT recommends "boring-on-purpose"; design brief requests exceptional glass UI | Follow the user's current design direction; preserve readable finance content. |
| GPT proposes Next.js + separate Node server + PostgreSQL + Docker | Treat as an option, not an existing dependency. Compare a simpler Workers/D1 deployment first. |
| CSV-only first versus OFX/QIF immediately | CSV first, based on a real anonymised bank sample; add other formats only when needed. |
| Three-column Sage CSV treated as universal requirement | Support mapping and preview. A vendor's format restriction is not our product requirement. |
| Automatic matches versus human confirmation | Show suggestions with reasons; require confirmation for financial allocations in v1. |
| Statement as open-invoice list versus opening/closing balance statement | Implement an activity statement with opening balance, movements and closing balance; offer outstanding-only as a separate filter. |
| Live item links in recurring invoices | Snapshot issued documents. Make future-template updates explicit and previewable. |
| Manually set Paid/Converted status | Derive payment balance and quote conversion from committed records. |
| Credit notes deferred while cancellation/write-off allowed | Provide auditable correction/reversal design before production; do not silently edit issued history. |
| 5 GB D1 free storage could be misread as a single database allowance | Official current limit is 500 MB per free database, 5 GB total account storage. |
| Grok alternates between USD and rand for a competitor's free-plan threshold | Do not use this figure for any purchasing decision without fresh verification. |
| "Not listed" bank interpreted as "not supported" | Absence from a page is insufficient evidence of non-support. |
| Forum complaints described as universal product defects | Preserve as historical user reports, not current reproducible defects. |
| "Self-hosted" equated with no lock-in | Managed services still have platform dependencies; export and restore are explicit requirements. |
