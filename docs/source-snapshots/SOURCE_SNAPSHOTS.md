How to make a snapshot by hand: open https://github.com/logiagenesis/plutus → green "Code" button → "Download ZIP" → rename it Plutus_source_<date>_<first 7 characters of the commit>.zip → drag it into this folder.

Customer data is not in these zips (it never goes in GitHub). It is in 04_Data.
